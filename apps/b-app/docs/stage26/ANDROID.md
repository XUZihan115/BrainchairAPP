# Stage 2.6 Android 模拟器验收记录

2026-10-19。API35 x86_64模拟器安装本阶段B APK，以独立Python发送器回放A APK中的真实EEG资产；没有操作A App、没有A/B手机。

默认参数0.65/0.15、3票、300ms，1000Hz/62通道/5样本每包；实测使用与离线相同的B生产算法和最终输出层。

## 已通过的行为检查

10项检查通过：先确认前进已稳定输出，再测试转静息、合法STOP、CRC错误、重新INFO推流、断流1.3秒、再次恢复及STOP，核对最终本地输出与接收计数。

- 8007个发送报文全部计入接收，其中1个故意制造CRC错误（正确拒收，不能计为有效EEG）。
- STOP的外部状态观测约226ms、134ms，均看到`流已结束 reason=1`与最终STOP。
- CRC错误后约114ms外部观测到最终STOP，错误计数确认为1。
- 断流1.3秒后最终STOP；新的INFO和完整新窗口可以恢复前进，旧结果不直接复用。

时间包含200ms诊断写入、ADB读取和轮询，不是内部STOP处理耗时，也不能作手机最坏上限。同步清理的内部时序由前后代码探针验证；模拟器只证明实际APK入口可触发相同行为。

## 仍然失败的路径

确认前进输出后，直接换成静息数据且不发STOP，仍观察到前进残留。9条观测记录涉及5个不同分析编号，最后一次运动观测约在切换后1.199秒。重复轮询记录不能当9个独立错误窗口。

因此`performance.json`中明确记为 **safetyAccepted=false**。本轮10项工程检查通过，不等同于“转静息识别安全通过”。不能用正常STOP测试替代无STOP异常路径测试。
