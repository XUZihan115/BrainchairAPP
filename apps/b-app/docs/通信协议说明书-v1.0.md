# BrainChair 教学通信协议 v1.0

本协议用于本项目 App 与模拟下位机，不是翔宇医疗的已确认协议。接真实设备前必须取得厂商文档并做适配，不能仅更换蓝牙地址。

## 传输与帧格式

经典蓝牙 SPP，UUID `00001101-0000-1000-8000-00805F9B34FB`。每帧固定 7 字节，所有数字为无符号单字节：

`AA 55 CMD ARG CHECK 0D 0A`，`CHECK = CMD XOR ARG`。

例：前进 30% `AA 55 01 1E 1F 0D 0A`；停止 `AA 55 05 00 05 0D 0A`。

接收端必须累积半帧、拆分粘包、丢弃噪声。校验或帧尾错误时向前移动一个字节，重新查找帧头。有效帧仍须检查命令和参数范围。

## App → 下位机

| CMD | 含义 | ARG |
|---|---|---|
| 01–04 | 前进、后退、左转、右转 | 0–100，实际不超过速度上限 |
| 05 | 停止 | 必须为 0，不清除锁定 |
| 06 | 设置速度上限 | 0–100；本版 App 仅允许 0–30 |
| 07 | 急停并锁定 | 必须为 0 |
| 08 | 心跳 / 查询状态 | 必须为 0，每 200ms |
| 09 | 明确请求解除锁定 | 必须为 0，只在已停止且心跳有效时接受 |

## 下位机 → App

| CMD | ARG 含义 |
|---|---|
| 81 | 电量 0–100% |
| 82 | ACK，回显已接受的 CMD |
| 83 | 故障码：0 正常，1 急停，2 心跳或运动指令超时，3 模拟故障 |
| 84 | 当前速度 0–100%，不是 km/h |
| 85 | 运行状态：0 停止，1 移动，2 锁定 |

每 200ms 发送一次状态组：81、84、85、83，共 28 字节。接受指令后立即 ACK 并回传状态组。状态组不具备事务原子性，UI 可能在一个接收周期内逐字段更新。

**修正手册中的歧义：** 手册用一个 ARG 字节描述四个状态量，容量不足；本版保留固定帧长，拆成四类状态帧。09 解除锁定和 84/85 状态帧是本项目明确增加的定义。双方必须同时使用本版本。

## 停车规则

- 默认速度上限 30%。按住方向键时每 200ms 重发运动指令；松手、取消触摸、切换页面、应用失去前台时清除运动意图。
- 下位机每 50ms 检查：距最近心跳或最近运动指令达到 500ms 时停车并锁定。实际检测延迟最多再增加一个检查周期；不是硬实时保证。
- 即便心跳持续，旧运动指令超过 500ms 也不能保持移动。
- 急停锁定后拒绝运动；恢复心跳、停止、重连均不等于解除下位机锁定。09 被接受后仍保持停止。
- App 收不到合法反馈达 1000ms 时断开，尝试停止。断连本身无法保证停止帧送达，最终停车必须依靠下位机看门狗。
- 本版手动重连；不自动恢复运动。不自动反复重连，避免大一项目引入复杂连接竞争。

## 局限与实机适配

ACK 只表示命令被接受，不证明物理执行完成。协议未含序号、认证、重放保护或强校验；XOR 不能检测所有多位错误。这是教学协议，不能直接用于载人轮椅。真实急停、故障复位条件、最大速度和看门狗必须按厂家接口实现，软件红色按钮不能替代物理急停。
