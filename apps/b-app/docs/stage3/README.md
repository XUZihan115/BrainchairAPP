### 正式2.5秒回归

使用既有 `output/stage25/data/segments.bin`、`segments.json`、通道表和 `plan.tsv`：同一OpenBMI受试者/会话，16个运动原始试次、2个静息片段；这批数据曾用于参数探索。新正式运行入口经原有协议、滤波、CCA、门控、投票、最终输出并实际发往UDP测试接收端。

- 72个分析窗口的相关值、门控、稳定和最终判决与既有2.5秒实验逐项一致；最大相关值差 **0.0**。
- 截止前稳定正确 **15/16运动试次**；成功试次采样时间均为3500ms；1个右转试次仍拒识。
- 这批窗口中的错误运动0，2个静息片段误动0；不是新的独立准确率、安全验收或长静息结论。
- 阈值保持 **0.65/0.15、三窗投票、300ms去抖**，没有调低阈值通过测试。

连续运动后的噪声拒识测试使用合成无标签数据，仅验证原门控拒识后最终发STOP，不能估计真实运动转静息的安全反应时间。旧多音合成fixture在2.5秒时左转差值约0.144，被0.15门控正确拒绝；传输测试换为独立宽带噪声背景的已知频率fixture，没有改算法/阈值。另修正测试时钟跳变后的滑窗调度；这些属于测试工具修正，真实回放回归保持上述原结果。

## 实测时间与性能

正式配置最早500ms预热+2500ms收集后约3秒门控，250ms间隔三窗约3.5秒稳定。按住持续发送时以滑动窗口更新，首次识别后无需再次清空收集。切换方向或新INFO才重新等待，并先停止旧运动。

API35模拟器通过宿主独立发送器回放真实片段，独立接收端累计收到 **119个合法指令数据报，0个无效**。以下均使用同一宿主单调时钟：

|情景|开始至接收端首个正确运动包|源信号结束标记至接收端首个STOP|
|---|---:|---:|
|前进，4秒后正常STREAM_STOP|3692.1ms|1.81ms|
|左转，新流独立识别后正常STOP|3704.1ms|0.85ms|
|前进，4秒后只断数据、故意无STOP|3666.9ms|928.3ms|

上述源信号结束标记在发送STOP前记录，包含测试发送器/网络/B调度时间；并非逐包ACK。停止前最近指令均为相应正确方向，无错误方向包。急停实际三包间隔 **32.14/31.15ms**。正常STOP与无STOP断流分开统计。

JVM另以200包/秒进行6秒持续信号及新方向发送，验证持续重发、方向先停再识别、停止及断流；具体时间线见本目录 `paced-udp-timeline.csv`。它使用合成信号测试系统控制，不计入真实EEG准确率。

模拟器日志去重观测到9次分析，计算时间中位 **2.95ms** / 观测P95 **9.19ms**，判决周期中位 **254ms** / 观测P95 **257.7ms**；采样Java堆最高 **8.86MB**。这是小样本调试观测，非长时间性能保证；`meminfo.txt`是重启后的单次PSS记录，也不是运行峰值。原始数据与精确统计在 [test-results.json](test-results.json)。

不能将B本机发送、测试接收器收到、真实Unity制动完成视为同一个事件。本轮没有真实Unity控制器/物理场景，所以没有真实Unity停车延迟结论。
