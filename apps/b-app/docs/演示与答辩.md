# 演示流程与答辩提示

## 两分钟演示

1. 说明本次使用模拟轮椅，没有真实 EEG 解码或电机动作。
2. 连接页点击“连接模拟轮椅”，确认顶部提示。
3. 进入控制页，按住前进，看到速度30%；松手后速度0%。再演示转向。
4. 点击底部急停，确认锁定。尝试方向键不能移动。
5. 点击解除急停，确认后仍保持停止。
6. 状态页显示电量、速度、状态、故障码和最近反馈；注入模拟故障，观察锁定。
7. 切到后台再回到 App，确认断开。重新连接后仍停止。
8. 可选：在控制页向上滑动，点击模拟“前进”意图，300ms后停止，说明这只是脑控结果接口演示。

## 答辩时要讲清

- 为什么先做模拟：没有测试硬件，但要先验证输入、协议、下位机状态和反馈的闭环。
- 为什么要拆包：蓝牙读到的字节不保证一帧一个包；解析器能处理半帧、粘包和噪声。
- 为什么加运动指令超时：仅有心跳不能证明用户仍希望继续移动。
- 为什么急停锁定：停止之后不能因残留方向命令立即重新移动。
- ACK 的边界：表示接收方接受了命令，不能证明真实轮椅已经按要求移动。
- 当前最重要的未完成项：安卓手机与真实 SPP 设备测试、厂家协议适配及真正 EEG 输入。

## 不应宣称

不能说“已经完成脑电识别”“已经验证真实轮椅安全”“可直接用于患者”或“支持任何蓝牙轮椅”。不能把模拟测试结果填写为真实硬件通过。
