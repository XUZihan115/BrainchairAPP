# Stage 2.5 Android 模拟器实测

2026-10-19，API35 x86_64 模拟器、B 端调试 APK，1000Hz/62通道，5样本/包，目标200包/秒。数据来自 A APK，但发送器为独立 Python 脚本，经模拟器端口转发进入 B 实际 UDP 服务。没有运行 A App，更没有 A/B 两台真机。

APK生产源码相对 Stage 2 没有变动；与Stage 2 APK对比，ZIP内部文件内容一致（重新构建后的APK容器哈希不同）。测试包：`output/stage25/BrainChair-B-stage25-validation.apk`，SHA256 `1D5AE2756E12D4E43A6596F74D21F699675D36A2B20EE71224737712F00B6FFA`。因此这次执行的是已经实现的 Android 算法，而非离线替代实现。

## 全部静息段拼接复查

追加按资产顺序循环两段静息两遍（16秒输入），这是标定和评价数据混合的描述性复查，不能算独立测试。收到3204/3204报文；采样到55个不同有效分析结果，全部稳定停止。

完整诊断CSV中观察到原始后退判决的窗口尾为4625、12410、12620；没能连续满足投票，稳定判决仍停止。离线固定步进在12600、12800出现稳定后退，两者窗口落点不同。这说明候选对采样调度/边界位置敏感；**不能因这一轮模拟器未误动，就将离线失败判为无效或批准候选阈值**。
