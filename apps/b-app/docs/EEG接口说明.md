# EEG 意图接口（演示）

本项目不采集脑电、不训练分类器。`IntentGate` 只校验外部解码结果，输入为：

| 字段 | 含义 |
|---|---|
| direction | 1 前进、2 后退、3 左转、4 右转、5 停止 |
| confidence | 0–1，必须是有限数，最低 0.8 |
| ageMs | 意图年龄 0–300ms，接入时必须使用一致的单调时钟计算 |
| sequence | 单调递增序号，重复或乱序拒绝 |
| armed | 操作者是否允许当前脑控输入 |

App 演示按钮生成置信度 0.95 的假“前进”意图，300ms 后停止。只对模拟轮椅开放。退出控制页、失去前台、手动操作或急停均取消脑控演示。

这不是已经完成的 EEG 设备对接。接入真实识别程序前需明确 SDK/传输方式、时钟、意图标签、置信度定义、连续确认策略及停止优先级。当前序号校验只在单次进程内有效。
