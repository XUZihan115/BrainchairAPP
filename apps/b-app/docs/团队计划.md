# 五人团队实施计划

本地已有初版代码不代表成员已掌握或实机验收已完成。保留手册 20 天为软件阶段，其余时间用于理解、硬件获取和反复联调。

| 阶段 | 任务 | 验收 |
|---|---|---|
| 第1周 / D1–D4 | 打开工程、运行模拟模式；A熟悉UI，B/C熟悉通信，D熟悉模拟器，E整理测试 | 每人能独立运行并讲清一帧数据 |
| 第2周 / D5–D10 | 阅读/修改控制和状态页面，检验协议解析、心跳和松手停止 | 可重复演示模拟闭环 |
| 第3周 / D11–D16 | 获取安卓手机与SPP设备，核对协议、配对连接、真实断电测试 | 实机测试记录，失败原因也要记录 |
| 第4周 / D17–D20 | 脑控接口演示、汇总测试、补录视频和答辩 | APK、协议、代码、报告、演示 |
| 第5–6周 | 如提供真实轮椅/脑控接口，再适配厂家协议 | 无人承载条件下由指导方安排验证 |
| 第7–8周 | 修复、复测、答辩演练与留出缓冲 | 每人讲清负责部分及项目限制 |

分工：A 管 MainActivity/res；B 管 CommManager；C 管 Protocol/协议文档与测试；D 管 ChairEngine/simulator；E 管 docs/测试和答辩。每日沟通昨天、今天、阻塞三件事。

仍待老师确认：仿真是否可验收、设备提供时间、厂家协议、EEG输出类型。Git 私有远程仓库需组长选择平台和账号后创建；目前不上传。
